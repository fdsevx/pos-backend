Kerjakan satu fase pembuatan backend sesuai permintaan user (contoh: "/fase 3").

1. Baca SPEC.md bagian I (Peta Fase), cari fase yang diminta.
2. Baca HANYA bagian SPEC yang dirujuk fase itu (bagian A dan B selalu dibaca).
3. Tulis rencana singkat: daftar file yang akan dibuat atau diubah. Jangan mengerjakan fase lain.
4. Implementasikan. Gunakan file yang sudah ada; jangan menulis ulang file yang tidak berubah.
5. Jalankan `npm run typecheck` dan perbaiki error sampai bersih.
6. Akhiri dengan daftar file yang dibuat/diubah (satu baris per file) dan langkah manual yang perlu dilakukan user (jika ada), tanpa penjelasan panjang.
